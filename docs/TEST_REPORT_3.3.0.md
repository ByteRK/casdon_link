## 2. 实现摘要

- 终端：新增顶部工具栏（清屏只清本地缓冲、复制全部、分享输出、字号）；字号持久化；输出与未发送输入在旋转/重建时恢复；连接状态带时间。
- 文件页：上传前可编辑设备端文件名并校验（空、`.`/`..`、`/`、控制字符），同名文件确认覆盖、同名目录拒绝；旋转保存当前目录与列表位置，重新读取后恢复；刷新/SAF 保存/目录删除文案沿用 3.2.0。

## 3. 限制与后续

- FILE-01 的可选“多选批量删除/下载、按名称/大小/时间排序”未实现。
- “复制全部”的剪贴板内容无法通过 adb shell 回读（Android 限制），仅确认按钮执行无异常。
- 连续两次旋转（竖→横→竖）后列表位置按最后一次保存的位置恢复，属于近似还原；单次旋转可保持目录与大致位置。
- 测试后已删除手机/设备上的测试文件与终端设置/历史，退出到首页，移除 adb 转发；设备授权与 Wi-Fi 未改动。
